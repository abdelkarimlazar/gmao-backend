# \# GMAO Backend

# 

# ASP.NET Core 8 REST API for a Smart Maintenance Management System (GMAO).

# 

# \## Technologies

# 

# \* ASP.NET Core 8

# \* Entity Framework Core

# \* MySQL

# \* JWT Authentication

# \* Swagger / OpenAPI

# \* Repository Pattern

# \* Service Layer

# 

# \## Features

# 

# \* Authentication and authorization

# \* User management

# \* Equipment management

# \* Breakdown management

# \* Maintenance task management

# \* Notifications

# \* Dashboard statistics

# \* Intent-based assistant

# 

# \## Project Structure

# 

# ```text

# Controllers/

# DTOs/

# Models/

# Services/

# Repositories/

# Data/

# Enums/

# Options/

# Migrations/

# Program.cs

# ```

# 

# \## Configuration

# 

# Before running the project, update `appsettings.json`:

# 

# ```json

# {

# &#x20; "ConnectionStrings": {

# &#x20;   "DefaultConnection": "server=localhost;port=3306;database=gmao\_intent\_db;user=YOUR\_USER;password=YOUR\_PASSWORD"

# &#x20; },

# &#x20; "Jwt": {

# &#x20;   "Key": "YOUR\_SECRET\_KEY"

# &#x20; }

# }

# ```

# 

# \## Run Project

# 

# ```bash

# dotnet restore

# dotnet run

# ```
